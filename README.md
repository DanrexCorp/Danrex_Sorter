# Danrex Sorter

Утилита для автоматической сортировки файлов по категориям. Входит в состав **Danrex Tools** — софт-направления **Danrex Corp**.

---

## Возможности

- Сортировка файлов по расширениям в подпапки
- Поддержка всех основных форматов
- Простой интерфейс — выбрал папку, нажал кнопку, готово
- Не требует установки
- Не требует интернета
- Если файл с таким именем уже есть — создаёт копию, не перезаписывает
- Полностью бесплатно

---

## Как использовать

1. Скачайте **Danrex Sorter.exe** 
2. Запустите (двойной клик)
3. Нажмите «Выбрать папку» и укажите нужную
4. Нажмите «Сортировать»
5. Готово — файлы разложены по категориям

---

## Категории

| Категория | Что попадает |
|-----------|--------------|
| Изображения | .jpg .png .gif .bmp .webp .svg .ico .tiff .psd .raw .heic .avif и другие |
| Документы | .pdf .docx .txt .xlsx .pptx .csv .json .xml .html .epub и другие |
| Видео | .mp4 .avi .mkv .mov .wmv .webm .flv .3gp и другие |
| Аудио | .mp3 .wav .flac .aac .ogg .wma .m4a .opus и другие |
| Архивы | .zip .rar .7z .tar .gz .bz2 .xz .iso .dmg и другие |
| Программы | .exe .msi .apk .bat .py .js .jar .sh и другие |
| Шрифты | .ttf .otf .woff .woff2 .eot |
| Базы данных | .db .sqlite .sqlite3 .mdb .accdb |
| Остальное | Всё, что не попало в категории выше |
